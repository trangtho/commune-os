# Tham chiếu giao diện Công dân

Ba ảnh được người dùng cung cấp và chọn làm chuẩn giao diện:

1. `01-trang-chu-mau.png` — trang chủ Công dân với banner xanh.
2. `02-danh-muc-mau.png` — danh mục thủ tục và bộ lọc.
3. `03-bieu-mau-mau.png` — biểu mẫu trực tuyến cho khai sinh.

Các ảnh này dùng tham chiếu thiết kế; **không phải ảnh chụp ứng dụng đã chạy**.
Giao diện thực hiện tại `apps/citizen/` dùng Tailwind CSS và dữ liệu PostgreSQL.
