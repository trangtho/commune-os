# Ảnh giao diện tham chiếu

Sáu hình ảnh `vai-tro-01.jpg` … `vai-tro-06.jpg` là bản thu nhỏ để đối chiếu thiết kế do người dùng cung cấp, tương ứng thứ tự công dân, cán bộ tiếp nhận, cán bộ xử lý, lãnh đạo xã, cấp trên và quản trị viên.

Code UI là một ứng dụng Nuxt 3 thống nhất, thay menu/nội dung theo vai, không tách 4 giao diện H–P–D–I. Ảnh tham chiếu chỉ là thiết kế mục tiêu, không phải bằng chứng màn hình đã chạy.
